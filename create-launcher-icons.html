📱 Create Launcher Icons for Simple Counter

Instructions

This tool creates all required launcher icon sizes:
1. Click "Generate All Icons" to create icons
2. Download each size individually
3. Save them in your project's mipmap folders
4. Make sure the 512x512 matches your Play Store listing icon
